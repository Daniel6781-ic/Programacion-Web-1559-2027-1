Resumen HTML: principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en programación web 1, en el modulo HTML

Conceptos principales HTML

HTML

El lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web

Elementos HTML

HTML es la unidad básica de estructura y contenido en una página web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head> Head

Es una etiqueta que se utiliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts

Etiqueta <body> body

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web

Contenedores Semanticos

<Header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, el menú de navegación principal, el nombre de la empresa, etc
<NAV> Etiqueta utilizada para el menú de navegación principal, suele tener contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe de haber mas de una en la página
<Main> Etiqueta unica de una página web, cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra página
<Section> Es una etiqueta que poco a poco se intenta que sustituya a <DIV> , su uso es para devidir a una página web de secciones y agrupar contenido relacionado
<Article> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<Footer> Es una etiqueta que normalemnte se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<Aside> Esta etiqueta representa una sección de la página web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/1515151020"
Este valor envía un whatsapp a un número especifico
href="mailto:example@gmail.com"
Envía un correo a un mail especifico

Elemento <form>

Es la manera en la que los usuarios de pueden comunicar con una página web, gracias a este elemento se pueden procesar datos de los usuarios según el objetivo de nuestra página
