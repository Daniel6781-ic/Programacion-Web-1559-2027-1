Tipos de estilos en CSS

Estilos en línea

Se van a agregar directamente en el elemento HTML mediante el atributo style pero puede dificultar la mantenibilidad del código si se abusa de esta técnica.

Este párrafo tiene estilos en línea

Estilos internos

Estos estilos se agregan en el mismo archivo HTML dentro de la etiqueta <style> en la sección <head> y para agregarlos se utiliza el elemento <style>.

Estilos externos

Estos estilos son los que se recomiendan utilizar ya que ofrecen modularidad, facilidad de mantenimiento, orden, eficiencia, entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <head> se utiliza el elemento <link> dónde se especifica la ruta de nuestra hoja de estilos y usamos el atributo rel establecido en "stylesheet" y el atributo href apuntando a la ubicación del archivo CSS.
